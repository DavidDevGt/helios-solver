# NNNN. Short title, imperative mood

Status: Proposed | Accepted | Superseded by [NNNN](NNNN-title.md)

## Context

What forces are at play (technical, project, organizational)? What's the
problem this decision resolves? Neutral description — this section should
be the same regardless of which way the decision ultimately went.

## Decision

The change/choice, stated plainly. One sentence if possible.

## Consequences

What becomes easier or harder as a result. Include the honest negative
consequences, not just the upside — and what would have to be true for this
decision to be revisited.
